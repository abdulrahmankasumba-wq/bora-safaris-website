# Bora Safaris – Official Website

**Your Gateway to African Safaris**

Bora Safaris is a Uganda-based tour company offering unforgettable wildlife safaris, adventure experiences, cultural tours and travel experiences across East Africa.

## About the Project

This repository contains the source code for the official Bora Safaris website. The website showcases safari destinations, tour packages, company information, wildlife experiences and contact channels.

## Destinations

- Uganda
- Rwanda
- Kenya
- Tanzania
- Burundi

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Key Features

- Responsive website design
- Safari destination guides
- Tour packages and itineraries
- Image galleries
- WhatsApp integration
- Facebook integration
- Contact and enquiry functionality
